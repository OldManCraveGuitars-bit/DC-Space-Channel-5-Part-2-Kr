# V1.103 초기화 시점 변경

`settings-core.S`와 `settings-core.ld`는 실제 빌드에 사용한 소스입니다. `initialization.diff`는 V1.102와의 차이입니다. 폰트 초기화는 상태·원래 글꼴 처리만 수행하고, TITLE 생성 진입에서 자막 초기화를 호출한 뒤 원래 12바이트 명령과 인수를 복원합니다.

빌드·검사 스크립트와 원본 바이트 명세도 첨부했습니다. 기존 객체·번역 데이터·원본 ROM을 포함한 로컬 작업 트리를 입력으로 사용하므로 이 공개 저장소만으로 완성 ROM을 재빌드할 수는 없습니다. C 객체 파일은 모두 V1.102와 바이트 단위로 동일합니다.
