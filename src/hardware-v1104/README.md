# V1.104 디스크 배치 수정

TITLE.BIN과 COSROOM.PVM을 마지막 150섹터 밖의 검증된 빈 공간으로 옮깁니다. 파일 내용과 크기는 그대로이며 ISO 위치 값과 해당 섹터만 수정합니다. 끝 150섹터 전체가 원본과 같은지도 확인합니다. 범용 생성 도구에도 같은 할당 상한을 적용했습니다.

V1.103의 실행 코드·자막·판정·VMU 코드는 바뀌지 않습니다. 동봉 스크립트는 로컬의 승인된 이전 빌드 및 원본 ROM을 입력으로 사용하므로 공개 저장소만으로 ROM을 재빌드할 수는 없습니다. 게임·BIOS 파일은 포함하지 않습니다.
