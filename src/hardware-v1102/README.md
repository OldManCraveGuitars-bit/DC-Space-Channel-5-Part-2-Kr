# V1.102 초기화 변경 소스

`voice-subtitles.c`는 이번 수정에 사용한 추가 자막 런타임입니다. `subtitle-init.diff`로 V1.101과의 변경을 비교할 수 있습니다. 변경 함수는 `subtitle_init`이며, BIOS 글꼴 주소를 얻던 부분을 RAM 글꼴 지정으로 바꾸고 훅 설치 구간의 SR 저장·인터럽트 차단·복원을 추가했습니다.

ASCII 글꼴은 기존에 배포하던 영덕 블루로드체를 12×24, 96칸(3,456바이트)으로 래스터화하여 기존 폰트 예약 영역의 `0x8c2eec80`에 넣었습니다. 파일 끝은 추가 BSS 끝인 `0x8c2f98a4`까지 0으로 채웠습니다. BIOS 글꼴 데이터는 포함하지 않았습니다.

전체 ROM 빌드에 필요한 원본과 생성된 번역 테이블은 공개 저장소에 포함하지 않습니다. 이 소스만으로 완성 ROM을 만들 수는 없습니다. 판정·설정 객체와 V1.101의 초기 캐시 어셈블리는 재사용했습니다.
