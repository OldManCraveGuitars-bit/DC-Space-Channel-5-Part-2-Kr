# 판정 설정 자세히 보기

V1.1에는 옵션 맨 아래에 **판정 설정**이 추가되어 있습니다. 1~6단계로 입력 성공을 인정하는 시간 범위를 조절합니다. **1단계가 원작 기준이며, 숫자가 높을수록 시간 판정이 관대해집니다.**

![판정 설정 6단계](screenshots/04-judgment-level6.png)

## 단계별 차이

게임 안의 “한 단계씩 올릴 때마다 20ms씩 증가합니다”는 **빠른 쪽과 늦은 쪽에 각각 20ms를 추가한다**는 뜻입니다.

| 단계 | 원작보다 빠른 입력 허용 추가량 | 원작보다 늦은 입력 허용 추가량 | 판정 폭의 전체 증가량 |
| :---: | ---: | ---: | ---: |
| **1 · 기본값** | 0ms | 0ms | 0ms · 원작 그대로 |
| **2** | +20ms | +20ms | +40ms |
| **3** | +40ms | +40ms | +80ms |
| **4** | +60ms | +60ms | +120ms |
| **5** | +80ms | +80ms | +160ms |
| **6** | +100ms | +100ms | +200ms |

위 표는 **원작 판정 범위에 더하는 시간**입니다. 원작의 전체 성공 범위가 20ms라는 뜻도, 6단계의 전체 성공 범위가 200ms라는 뜻도 아닙니다. 원작 범위는 상황에 따라 달라질 수 있습니다.

원작에서 빠른 쪽 경계를 E, 늦은 쪽 경계를 L이라고 하면, N단계는 대략 **E − 20×(N−1)ms ~ L + 20×(N−1)ms** 범위로 확장됩니다. 예를 들어 4단계는 원래보다 60ms 일찍, 또는 60ms 늦게 들어온 입력까지 추가로 받아들일 수 있습니다. 6단계는 양쪽 각각 0.1초를 추가합니다. 실제 내부 값은 게임의 템포와 정수 시간 단위로 환산됩니다.

## 조작 방법

1. 메인 메뉴에서 **옵션**을 엽니다.
2. 방향키 위·아래로 **판정 설정** 행에 커서를 둡니다.
3. **오른쪽 / A / START**로 다음 단계, **왼쪽**으로 이전 단계를 선택합니다.
4. 값은 **6 → 1**, **1 → 6**으로 순환하며, 변경한 설정이 즉시 적용됩니다.

선택한 숫자는 밝게, 나머지 숫자는 반투명하게 표시됩니다. 행 선택 여부에 따른 제목과 숫자의 색상 규칙도 다른 옵션 메뉴와 맞췄습니다. 판정을 원작 기준으로 돌리고 싶으면 이 행에서 **1**을 직접 선택해 주세요.

## 무엇이 달라지나요?

- **시간 허용 범위만 넓어집니다.** 원작의 입력 기준 시점과 음악 속도는 유지합니다.
- 방향이나 버튼을 맞춰야 하는 규칙은 유지합니다. 버튼 하나를 누르면 모든 지시가 성공하는 기능은 아닙니다.
- 한 번의 입력을 소비하는 방식, 누르기·떼기 처리, 원래 점수 계산 흐름을 유지합니다. 판정 성공이 늘면 그 결과로 시청률과 플레이 결과는 달라질 수 있습니다.
- 음악을 앞당기거나 늦추는 보정값이 아닙니다. 디스플레이·컨트롤러 지연을 따로 측정하거나 보정하는 설정과는 용도가 다릅니다.
- 한국어 자막과 노래 가사 표시 설정은 별도입니다. 판정 단계를 바꿔도 대사 문구나 음악은 바뀌지 않습니다.

원작 감각을 유지하려면 **1**, 조금 여유 있게 적응하고 싶으면 **2~3**, 리듬 입력이 어려운 구간을 넉넉하게 플레이하려면 **4~6**을 선택할 수 있습니다. 곡의 속도나 입력 순서는 그대로이므로, 높은 단계에서도 다음 지시를 듣고 맞는 입력을 해야 합니다.

## VMU에 자동 저장

판정 단계는 게임 진행 데이터와 분리된 전용 설정 파일에 저장합니다.

| 항목 | 내용 |
| --- | --- |
| 설정 파일 | `SC5P2KR_JDG` |
| 사용 공간 | **2블록 · 1,024바이트** |
| 게임 진행 저장 | `SC5PART2_DAT` · 별도 유지 |
| 저장 시점 | 단계 변경 후 자동 저장 |
| 읽는 시점 | 게임을 새로 시작할 때 유효한 설정을 읽어 복원 |
| 유효한 설정이 없을 때 | **1단계** |

변경 후에는 **수초 정도 기다린 다음 종료**해 주세요. VMU 작업 상황에 따라 실제 저장까지 걸리는 시간이 달라질 수 있습니다. 에뮬레이터에서는 다음 실행에도 같은 가상 VMU를 연결해야 설정을 이어서 읽습니다.

VMU가 없거나 공간이 부족해도 이번 실행 중 선택한 단계는 적용됩니다. 다만 다음 실행까지 저장된다고 보장할 수는 없습니다. 유효하지 않거나 다른 용도로 보이는 같은 이름의 파일은 보호하며 강제로 덮어쓰지 않습니다. 카드가 다시 연결되면 연결 상태를 다시 확인합니다.

게임 진행 파일의 형식은 바꾸지 않습니다. **게임 내 저장으로 이어하기**와 **판정 설정 자동 저장**은 서로 다른 저장 작업입니다. 에뮬레이터의 상태 저장은 실행 중 메모리까지 복원하므로, 패치 버전 확인은 새로 부팅한 상태를 기준으로 해 주세요.

## 확인한 범위

기존 시험 기록에서 일반 Flycast 코어의 새 부팅으로 VMU의 6단계를 복원하고, 메뉴 조작으로 5단계를 저장한 뒤 파일과 CRC를 확인했습니다. 기존 게임 진행과 다른 파일이 그대로인 것도 확인했습니다. V1.1 배포에서는 해당 구현을 유지하고 최종 패치 적용 결과 해시를 검사했습니다.

모든 곡·두 플레이어·모든 입력 경계의 실제 플레이를 다시 확인한 것은 아니며, 실기와 ODE 호환은 별도 확인이 필요합니다. 자세한 구분은 [검증 범위](VERIFICATION.md)에 기록했습니다.
