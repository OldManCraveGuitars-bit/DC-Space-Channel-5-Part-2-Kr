# V1.105 · 스테이지 4 방향 지시 오역 수정

스테이지 4에서 마이클을 구출한 뒤 퍼지·로봇과 싸우는 구간의 방향 지시를 수정했습니다.

| 이전 | V1.105 |
| --- | --- |
| 하나 더 해! | **한 번 더 뒤!** |

원문의 `もうひとつうしろ`는 뒤쪽 방향을 지시하는 말입니다. [오역 제보 #1](https://github.com/OldManCraveGuitars-bit/DC-Space-Channel-5-Part-2-Kr/issues/1)을 반영했습니다. 자막 시간·위치·투명도는 유지됩니다.

수정 대상은 `R43VOICE.AFS:014`에 연결된 자막 한 문장입니다. 표시 시간은 기존의 0~1,064ms이며 위치와 색상, 반투명 배경도 유지됩니다.

## 반영 및 확인

- 번역 입력과 실제 롬의 자막 테이블을 함께 수정했습니다. 기존 글꼴에 있는 글자를 사용합니다.
- `ZENFONT.GD` 안의 해당 문장 포인터와 새 문장 데이터만 변경했습니다. 파일 크기와 디스크 위치는 같습니다.
- V1.104 대비 Track 3의 원시 섹터 2개만 변경됩니다. 그 외 모든 섹터와 다른 ISO 파일 252개는 동일합니다.
- 실행 코드의 바이트와 디스어셈블리, 부팅·메뉴·판정 설정·VMU 저장 코드는 동일합니다.
- 배포 적용기로 지정된 일본판 원본에서 GDI를 생성하고, 결과 4개 파일의 SHA-256을 대조했습니다.
- CUE 결과의 해시는 빌드 결과에서 계산했습니다. 이번에는 CUE 적용을 중복 실행하지 않았습니다.

전체 플레이, 새 음성 재생 및 화면 검수는 반복하지 않았습니다. 기존 실기 호환성의 미확인 상태도 그대로입니다. 이전 선택바 제보에 대한 추가 코드 변경은 포함하지 않습니다.
