# V1.101 배포 확인 범위

## 이번 부팅 호환성 수정에서 확인한 것

초기 SH-4 캐시 처리와 원래 함수 재배치, 자막 데이터 보존, 메모리 경계, V1.1 대비 변경 21섹터와 EDC/ECC를 검사했습니다. IP.BIN과 ISO 파일 위치, 나머지 ISO 파일 251개는 유지했습니다.

배포 Windows 적용기로 원본에서 CUE/GDI를 각각 만들고 총 8개 결과 파일의 크기·SHA-256을 대조했습니다. 원본 4개 파일은 읽기 전용으로 사용하고 보존 해시를 확인했습니다.

**실제 Dreamcast/ODE 부팅 성공은 아직 확인하지 않았습니다.** 검사 모델은 새 부팅 명령의 순서를 검증하며, 실기 동작을 대신하지 않습니다. 이번에 전체 플레이·추가 음성·화면 검수를 다시 진행하지 않았습니다.

## 기존 확인 기록을 유지한 것

- 일반 Flycast 코어에서 새 부팅으로 판정 단계 6을 VMU에서 복원했습니다.
- 메뉴 조작으로 단계 5를 저장하고 VMU 설정 데이터와 CRC를 확인했습니다.
- 기존 게임 진행과 관계없는 VMU 파일은 바이트가 유지됨을 확인했습니다.
- 판정 메뉴의 선택 색상, 1~6단계 표시, 설명 문구의 기존 게임 캡처를 보관했습니다.

## 구분해야 할 부분

V1.101은 이 비공식 한글 패치의 정식 배포 버전 명칭입니다. SEGA의 공식 한국어판이나 실기 인증을 의미하지 않습니다.

최신 추가 대사·노래·엔딩 자막은 데이터와 연결을 수정한 상태입니다. 이번 배포를 위해 전체 스테이지를 다시 플레이하거나 새 음성을 재생하여 모든 타이밍과 누락 해소를 확인한 것은 아닙니다. 엔딩송의 일부 표현은 조사 자료의 추정 의미를 바탕으로 번역하여 원문 해석과 타이밍에 보완 가능성이 남아 있습니다. 실기·ODE 및 모든 입력 경계의 동작도 별도 확인 범위입니다.

소스의 자막 테이블 수에는 재생 경로별 연결이 포함되므로 이를 고유 대사 수 또는 번역 완료율로 세지 않습니다. 갤러리 역시 작업 중 남겨 둔 실제 캡처이며 최신 모든 변경의 화면 검증 증거로 제시하지 않습니다.

문제를 제보할 때는 스테이지, 직전 대사, 재현 위치, 사용 중인 Track 3 해시를 함께 알려 주시면 수정 지점을 찾는 데 도움이 됩니다.
